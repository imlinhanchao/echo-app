我在年轻时候也曾经做过许多梦，后来大半忘却了，但自己也并不以为可惜。 所谓回忆者，虽说可以使人欢欣，有时也不免使人寂寞，使精神的丝缕还牵着已逝的寂寞的时光，又有什么意味呢，而我偏苦于不能全忘却。 这不能全忘的一部分，到现在便成了《呐喊》的来由。

设计哲学

为深度阅读与专注听书而生

去除音乐播放器的喧嚣霓虹与冗余装饰，用暖墨与纸白构建克制耐看的阅读容器。

极简书房与离线书库

暖墨黑（#0D0E10）与羊皮纸白（#F8F5F0）双色对偶，自动生成 2:3 复古布面兜底封面。内置纯 Dart EPUB 2/3 与 TXT 解析器，免部署服务器即可导入开读，也支持接入 Ebook API 搜书下载。

边听边看与即时倍速

边听边看状态下句级高亮平滑联动；支持 0.5x–2.5x（0.05x 步进）不重合成、不中断句子的即时变速不变调调节，并可一键按章在后台离线生成分块有声书。

沉浸分页与无遮挡划线

按视口尺寸精确分页与缓存，阅读默认防锁屏常亮。长按选词触发五级智能避让浮动工具栏，彻底避免遮挡正文与拖动手柄，支持五色墨色下划线、笔记筛选与跨章直达。

锁屏与耳机原生播控

通过系统级媒体会话接入 Android 锁屏卡片与通知栏播放器，保持音频焦点与前台服务稳态，支持蓝牙及线控耳机锁屏暂停与恢复，并在主动停播时自动撤销通知栏。

端侧语音

完全运行在设备本地的语音引擎

支持本机系统引擎零下载即开即用，亦内置多款精选 Sherpa-ONNX 离线神经语音模型与国内加速镜像切换。
