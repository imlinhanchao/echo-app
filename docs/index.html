设计哲学

为深度阅读与专注听书而生

去除音乐播放器的喧嚣霓虹与冗余装饰，用暖墨与纸白构建克制耐看的阅读容器，并持续进化全链路端侧 AI 与书源生态。

极简书房与静默更新

暖墨黑（#0D0E10）与羊皮纸白（#F8F5F0）双色对偶，自动生成 2:3 复古布面兜底封面，纯 Dart 解析 EPUB 2/3 与 TXT；内置按 IP 地区自动切换加速镜像的更新检查、Markdown 更新日志与 Android 后台保活静默下载。

免部署书源与发现荐书

全新 book-sources.v1 端侧书源引擎支持通用规则与 OPDS 书库双驱动，开箱内置 3 个公版书库；「发现」页集成托管荐书榜单（discover-rules.json），支持一键联动搜书。参阅 书源制作与 Skill 指南。

端侧离线翻译与双语对照

集成腾讯 HY-MT1.5-1.8B 离线神经翻译引擎（~440 MB 1.25-bit 极速量化版 / Q4_K_M / 本地导入 GGUF），Android ARM64 原生 llama.cpp FFI 离线推理；支持原文 / 双语对照 / 仅译文三模式、9 种语言与译文联动朗读。

边听边看与现场音色克隆

边听边看句级高亮平滑联动，支持 0.5x–2.5x（0.05x 步进）不重合成即时变速不变调与按章转有声书；ZipVoice 新增应用内参考音色现场录制页（引导台词、24 柱实时声波与试听），零门槛克隆声音。

沉浸分页与无遮挡划线

按视口尺寸精确分页与缓存，阅读默认防锁屏常亮。长按选词触发五级智能避让浮动工具栏，彻底避免遮挡正文与拖动手柄，支持五色墨色下划线、笔记筛选与跨章直达。

锁屏与耳机原生播控

通过系统级媒体会话接入 Android 锁屏卡片与通知栏播放器，保持音频焦点与前台服务稳态，支持蓝牙及线控耳机锁屏暂停与恢复，并在主动停播时自动撤销通知栏。

端侧 AI 引擎

完全运行在设备本地的语音与翻译模型

零云端依赖、不上传文本隐私。支持系统语音、Sherpa-ONNX 离线音色与腾讯 HY-MT1.5 端侧离线翻译模型，均支持国内加速镜像、自定义反代前缀与断点续传。
