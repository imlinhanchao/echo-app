## 1. 产品定位与核心闭环

**回声**：跨平台（Android 已实现；平板/桌面/鸿蒙待做）的**听看一体书客户端**。

产品判断：**这是「书」，不是音乐播放器**。听书界面的主角是文字与章节，不是封面氛围；进度单位是章节，不是曲目。

```
搜索（zlib 书源）→ 下载（入书库）→ 转有声书（TTS，产出音频 + 句级 SRT）
                                              │
                            ┌─────────────────┴─────────────────┐
                            ▼                                   ▼
                     听：播放器（SRT 跟读）              看：阅读器（精确分页）
                     两态共享同一份进度与章节定位
```

关键设计结论：

1. **跟读高亮免费获得**：TTS 转换本身产出句级 SRT，无需独立对齐管线；
2. **听与看是同一份资产的两种视图**：详情页「从当前位置听」把阅读位置映射到对应音频分块。

## 2. 设计系统落地

### 2.1 Token 三层模型

```
design-tokens.json（primitive 原始色板）
        │ 运行时 asset 载入
        ▼
EchoTokens : ThemeExtension（semantic 语义层，light/dark 双值）
        │ buildEchoTheme()
        ▼
ThemeData（component 层：卡片/按钮/输入框/底部弹层…）
```

实现文件：

| 文件 | 职责 |
| --- | --- |
| [`assets/design-tokens.json`](../assets/design-tokens.json) | 唯一视觉真相（颜色/字阶/间距/圆角/动效/可访问性门槛） |
| [`lib/design/echo_tokens.dart`](../lib/design/echo_tokens.dart) | Token 解析器：支持 `#RRGGBB` / `#AARRGGBB` / `rgba()`；light 无 `reading` 段时降级 |
| [`lib/design/echo_metrics.dart`](../lib/design/echo_metrics.dart) | 间距（8pt 网格）、圆角、动效时长与曲线常量 |
| [`lib/design/echo_theme.dart`](../lib/design/echo_theme.dart) | 用 Token 构建 Material 3 `ThemeData` |
| [`lib/design/book_cover.dart`](../lib/design/book_cover.dart) | 真实封面组件（网络加载 + 暖橙渐变降级） |

**硬规则**：组件中禁止出现裸色值与魔法数字，一律走 `Theme.of(context).extension<EchoTokens>()!` 与 `EchoMetrics`。

### 2.3 字阶与排版

- 单位 `rem`，正文 1rem / 行高 1.6；元数据 0.75rem；全局下限 14px；
- 阅读器正文：**衬线字体**、行高 1.9、行长受版心约束（按可视尺寸精确分页）；
- 跟随系统字号（`MediaQuery.textScalerOf`），不锁定缩放。

### 2.4 圆角 / 间距 / 动效

| 类型 | 值 |
| --- | --- |
| 圆角 | 卡片 12、控件 8、胶囊 999、底部弹层 16 |
| 间距 | 4 / 8 / 16 / 24 / 32 / 48（8pt 网格，4 用于微调） |
| 动效 | 快 150ms / 基准 250ms / 弹层 300ms；进场 ease-out、退场 ease-in；仅动 `transform`/`opacity` |

### 2.5 图标

- **应用图标**：AI 生成「深蓝底 + 靛蓝同心弧（回声意象）」，输出 5 档 mipmap（48/72/96/144/192），另存 512 商店图；
- **图标系统**：Material Icons（未使用 emoji 充当 UI 图标）；
- 截图：[`docs/screenshots/v020-app-icon.png`](screenshots/v020-app-icon.png)。

### 2.6 亮暗模式

深色为品牌基准态（dark-first），我的页提供开关，偏好持久化到 `flutter_secure_storage`；双态由同一 `buildEchoTheme()` 产出，均有测试覆盖。

## 5. 交互规范（已实现）

### 5.1 播放器 v3（四区）

```
┌────────────────────────────────────────┐
│ ⌄  [封面] 书名 / 1-1 · 章节名   📝 ‹ › │  顶栏（含笔记、上下章）
├────────────────────────────────────────┤
│        ……上一句（暗）                  │
│   ▍当前朗读句（主色加粗，垂直居中）     │  跟读区：自动滚动到中线
│        ……下一句（浅）                  │
├────────────────────────────────────────┤
│ 01:08 ──●── 章节刻度点 ──  04:11       │  进度：跨章拖动
│ (上一章) (-15s) ((播放)) (+15s) (下一章)│  圆形控件簇
│   倍速 1.0x    睡眠定时    章节列表     │  次级入口
└────────────────────────────────────────┘
```

- **跟读居中**：`Scrollable.ensureVisible(alignment: 0.5)`；因 `ListView` 懒构建，先用索引粗跳到目标附近，目标构建后再精确居中（最多 3 次逐帧微调）；
- **章节切换**：顶部圆形按钮 / 底部控件簇 / 左右滑动跟读区 / 锁屏上一首下一首（映射为章节）；
- **±15s 跨块**：块尾前进自动切下一块并换算偏移；
- **睡眠定时**：15/30/60/90 分钟，到点自动暂停并保存进度；
- **断点续听**：恢复「块 + 偏移」；若上次已听完（距末尾 ≤2s）则从头重播；
- **背景**：深蓝渐变（primary 16% → surface），顶部封面缩略，全屏路由上滑进入。

### 5.2 阅读器

- **精确分页**：`TextPainter` 二分实测高度，保证每页渲染高度 ≤ 版心高度；切点回退到句读（`。！？；，`、换行）；
- **翻页**：`PageView` 左右滑动；跨章自动衔接；
- **目录**：顶栏「目录」→ 底部抽屉列出全部章节（章名 + 字数），点击跳该章首页；
- **进度**：底部 `页码/总页 · 百分比`（如 `22/229 · 10%`）；
- **位置记忆**：以「章号 + 章内字符偏移」持久化，改字号/换屏重排后仍能定位；
- **从当前位置听书**：顶栏耳机 / 底栏按钮 → 定位到该书有声书对应章节分块起播并打开播放器；
- **排版**：衬线字体、`paper.warm` 底 + `paper.text` 字、行高 1.9、字号三档（0.9x / 1.0x / 1.18x）。

### 5.3 书籍 / 有声书详情页

- 大封面 + 标题/作者 + 元信息胶囊（格式/年份/语言/有声书数）；
- 简介 4 行折叠，点击展开；
- 有声书列表：模型/音色/时长、播放、离线下载/删除、已下载角标；
- 章节预览（前 6 章）；
- **主操作按资产智能切换**：有有声书 → 继续收听 + 阅读原文 + 再转一版；纯文本 → 开始阅读 + 转有声书；
- 右上菜单：**导出 EPUB**（下载后调起系统分享）。

### 5.4 离线下载

- 按分块下载 `音频 + SRT`，并缓存**章节清单 manifest.json**（离线播放必需）；
- 文件位于 `<app documents>/echo_offline/<audiobookId>/`；
- 详情页显示进度、完成后「已下载 · 离线可听」，可删除；
- 播放器优先读本地文件（`file://`），断网可正常播放；清单请求失败时回退本地清单，并沿用同一套续听规则。

### 5.5 时间戳笔记

- 播放器顶栏笔记按钮 → 面板显示「当前位置 HH:mm」，输入框预填当前朗读句；
- 列表按时间倒序，`HH:mm` 胶囊 + 内容 + 章节名；点击跳转到该位置，可删除；
- 存储：`flutter_secure_storage`（键 `echo_notes_v1`），节流保存。

### 5.6 收听统计

- 我的页统计卡：**本周收听时长 / 连续收听天数 / 已听完本数**；
- 采集：播放位置正常推进时累计（跳过 seek 跳变，单次增量 ≤5s）；阅读翻页计为当日活跃；整本播完计入「已听完」；
- 存储：键 `echo_stats_v1`，节流保存（无 Timer，避免测试残留）。

### 5.7 搜索与筛选

- 关键词搜索 + 「仅 EPUB」快捷筛选；
- 高级筛选：语言多选（中/英/日/德/法/西/俄）、出版年份范围、排序（相关度/最热/最新）；按钮显示已启用条件数；
- 结果行：封面/标题/作者/年份 + 格式与大小胶囊 + 下载按钮；点击行打开详情弹层（简介 + 下载）；
- 搜索历史胶囊（置顶去重、可删）。

### 5.8 任务中心

- 下载 / 转有声书任务列表，页面可见时 3s 轮询；
- 进行中显示进度条，失败直显服务端错误原因，可取消；
- 有任务新完成时自动刷新书架。

### 5.9 书架

- 问候语（按时段）→ 搜索入口 → 「正在收听」大卡（封面 + 圆形播放键 + 剩余时长 + 进度条）→ 有声书行 → 书库行；
- **只展示已完成与转换中的有声书**；失败/取消不在首页展示（保留在任务页与详情页）；
- 行内 `⋮` 菜单删除（二次确认）；下拉刷新。

### 5.10 可访问性

- 触控目标 ≥48dp，播放主按钮 64dp；
- 正文对比 4.5:1，UI 控件 3:1；
- 亮暗双模式均设计并验证；图标不使用 emoji。

## 6. 技术架构

### 6.1 分层

```
lib/
├── core/                    基础设施
│   ├── api/                 EchoApi（dio + Bearer + 401 自动 refresh）+ models
│   ├── auth/                Token 存储（secure storage / 内存）
│   ├── audio/               分块播放引擎（just_audio / audio_service）+ SRT 解析
│   ├── offline/             离线文件与下载管理
│   ├── reader/              阅读分页算法 + 阅读位置存储
│   ├── notes/               时间戳笔记存储
│   ├── stats/               收听统计
│   ├── export/              EPUB 导出
│   ├── media/               封面本地缓存
│   └── settings/            亮暗模式
├── design/                  Token / 主题 / 尺度 / 封面组件
├── features/                按功能切分（auth/library/player/reader/search/jobs/providers/profile/shell）
└── main.dart                启动装配（audio_service / 离线目录 / 统计 / 笔记 / 主题）
```

### 6.2 关键机制

| 机制 | 实现要点 |
| --- | --- |
| 认证 | `POST /api/auth/token` 换 `echo_pat_`；401 拦截器自动 `refresh` 并重放一次，失败则清理并跳登录；媒体请求带同一 Authorization 头 |
| 播放引擎抽象 | `AudioEngine` 接口；生产用 `AudioServiceEngine`（Android/iOS，锁屏播控）/ `JustAudioEngine`（桌面回退）；测试用 `FakeAudioEngine` |
| 分块播放 | manifest 驱动；块间无缝续播；`±15s` 跨块换算偏移；进度模型 `{chapterIndex, chunkN, offsetMs}` 听看共享 |
| 跟读 | 按块取 SRT → 句级时间轴 → 当前句高亮 + 居中滚动；无字幕降级封面模式 |
| 离线优先 | 播放前先查本地文件；清单失败回退本地缓存的 manifest |
| 状态管理 | Riverpod：`Provider` 持有 API/引擎/存储，`StateNotifierProvider` 持各控制器 |
| 错误契约 | 服务端 `{"error":{"code","message"}}` → `ApiException`，UI 直显中文文案 |

### 6.3 依赖

`dio`、`flutter_riverpod`、`flutter_secure_storage`、`just_audio`、`audio_service`、`permission_handler`、`path_provider`、`share_plus`。

1. **华为 / HarmonyOS 锁屏媒体卡片不显示**：通知被系统当普通通知渲染（折叠态无封面无按钮）。已尝试提高通知渠道重要性、常驻通知、封面本地化，其中「渠道 DEFAULT + 自定义图标」版本反而导致通知消失，已回退。**需真机 logcat 或系统通知设置截图才能继续定位**，当前搁置。
2. **仅手机断点**：平板/桌面布局未实现。
3. **鸿蒙未验证**：未用 OpenHarmony Flutter SDK 构建。
4. **无跨设备同步**：服务端无进度接口，进度/笔记/统计均本地。
5. **发现页无推荐位**：无编辑精选/榜单接口，当前「发现」即搜索页。
6. **阅读器缺少书签与选中划线笔记**；笔记仅支持播放器打点。
7. **有声书详情未做独立页**：复用书籍详情页的音有声书列表。
8. `关于` 中版本号在代码里硬编码（未接 `package_info_plus`）。
