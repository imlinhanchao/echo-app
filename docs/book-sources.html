book-sources.v1 · 声明式书源引擎 & Agent Skill

免部署制作书源
用 AI Skill 一键评估与校验

Echo 客户端直接内置声明式书源解析引擎与 OPDS 书库支持，无需部署后端服务器即可通过 JSON 或远程订阅扩展书库。仓库随附 echo-book-source-author Skill 与纯 Dart 校验工具，无论交给 AI 代理自动编写，还是参考模板手写规则，都能快速完成验证并安全导入。

Step 1 · AI Skill 实战

用 echo-book-source-author Skill 自动写书源

Skill 内置于仓库 .agents/skills/echo-book-source-author/，教 AI 严格按「网络嗅探判定 → 规则生成 → CLI 校验干跑 → 安全脱敏审计」四步工作，不会瞎编无法运行的规则。

在 Antigravity、Claude Code、Codex、Cursor 或 OpenCode 中打开 echo-app 仓库时，Agent 会自动发现 .agents/skills/echo-book-source-author/，并可直接调用仓库自带的纯 Dart CLI 对网络连通性与真实搜书结果做端到端干跑校验（无需启动模拟器）。

1. 克隆仓库并进入工作区（Skill 自动生效） 
git clone https://github.com/imlinhanchao/echo-app.git
cd echo-app
2. 使用内置纯 Dart CLI 执行严格校验与只读搜书干跑（不消耗下载配额） 
# 静态 Schema + 模板变量 + Dart RegExp + 敏感头脱敏校验
dart run .agents/skills/echo-book-source-author/scripts/validate_source.dart \
  path/to/your-source.json --strict

# 附带镜像探测与真实只读搜书 + 详情页提取测试
dart run .agents/skills/echo-book-source-author/scripts/validate_source.dart \
  path/to/your-source.json --source your_source_id --search "红楼梦" --probe --strict

如果希望在其他项目或空目录里也随时调用 echo-book-source-author，可以通过 npx skills 一键安装，或将技能目录复制到对应客户端的全局 Skills 目录。注意：纯 Dart validate_source.dart CLI 仍需在已拉取 echo-app 依赖的仓库中运行，或使用本页下方浏览器校验器做静默语法检测。

Step 2 · 可行性评估

动手前先判可行性：网站可行性决策矩阵

建议先用浏览器 DevTools（Network 面板）或 curl 观察目标站的「探针 → 搜书 → 详情 → 登录 → 下载」5 个阶段，再决定采用哪种方案。

架构安全边界：Echo 的 rule 引擎是纯声明式引擎，刻意不内置 JS 执行器（QuickJS / V8）与隐藏 WebView；且书架本地导入当前仅支持 .epub 与 .txt 格式。
目标站点网络特征 判定结论 推荐方案
标准 /opds Atom XML 或 OPDS 2.0 JSON（如 Calibre / Komga） 直接可转 选用 driver: "opds"，填写目录地址与可选 Basic 认证即可工作
明文 JSON API / OpenAPI v2（支持 cursor 游标分页、CSRF 登录与轮询） 直接可转 选用 driver: "rule"（mode: "json" + auth + poll）
服务端直出 HTML（搜索列表 + 详情页 + <script type="application/ld+json"> / 直链） 直接可转 选用 driver: "rule"（mode: "html" + 两步 download.steps），建议设 min_request_interval_ms >= 800
校验常规浏览器 User-Agent + Origin / Referer，无 JS 挑战 可转（需补头） 在顶层 headers 与 image_headers 配置贴近浏览器的常规请求头
存在 Cloudflare Turnstile / hCaptcha / 滑块或每次登录下载强制图形验证码 不可直接转 静态规则无法自动过人机验证，请优先使用站点官方开放 API 或放弃接入
参数或下载链接依赖混淆 JS 签名（动态 AES / WASM Token）或 DRM 加密 不可转规则 切勿硬拼脆弱正则；若无开放接口，应诚实标注为「不支持」
全站仅有加密在线阅读或仅提供 .pdf / .azw3 且无 .epub / .txt 不适于有声书 Echo 书架目前仅支持导入 .epub 与 .txt，不建议制作该源
Step 3 · 规则结构与模板

book-sources.v1 驱动类型与标准范例

支持导入单条书源对象（Single Source）或合集（Bundle，含 config_version 与 config_ttl_hours）。以下全部模板均使用 example.org 占位并可通过严格校验。

driver: rule

通用规则引擎

解析 JSON / HTML CSS / JSON-LD / XML，内置多镜像故障转移（健康节点缓存 10 分钟）、CSRF 预处理、游标分页与异步轮询下载。

driver: opds

OPDS 原生书库

原生兼容 OPDS 1.2（Atom XML + OpenSearch）与 OPDS 2.0 JSON，自动发现搜索模板并按 prefer_formats 选择 epub / txt。

适合自建 Calibre-Web、Komga、Audiobookshelf OPDS 或标准 OPDS 目录，一般只需填写域名与可选认证模式即可。

模板变量命名空间速查（{{...}}）

  • {{origin}}：当前选中的镜像基地址（自动去除末尾斜杠）。
  • {{query.q}} / {{query.page}} / {{query.limit}} / {{query.offset}}：搜索词与分页参数。
  • {{book.ref}} / {{book.ref_parts.0}} / {{book.var.<key>}}：书籍引用 ID、按 ref_separator（默认 :）拆分片段，以及预提取变量（缺失时自动调 detail 补全）。
  • {{input.<key>}} / {{cred.<key>}}：登录表单输入值与保险箱已保存凭据。
  • {{step.<step_id>.<key>}}：前置步骤或轮询提取的值（也可用 {{step.last.<key>}}）。
  • {{vars.<key>}} / {{fields.<key>}}：单条记录解析阶段内先求值的中间变量或标准字段。
  • {{rand.uuid}} / {{rand.id_24}}：随机 UUID v4 与 24 位字母数字串（同次请求内缓存复用）。

提取器定位与后处理管道（BookSourceExtractRule）

  • JSON 定位：path（点分路径）、paths（回退列表）、path_segments（精准键名数组，适合 application/epub+zip 等含 / 或 . 的键）。
  • HTML / XML 定位：selector / selectors、attr / attrs、all: true、preserve_paragraphs、next_sibling、after_heading、json_path（提取 ld+json 脚本内部字段）。
  • 组合与条件：cookie、first_of（顺序回退数组）、when_present + const_value、template。
  • 后处理顺序：strip_prefix/suffix → regex/regex_group → replace_pattern/with → prefix → transform (lower/upper/trim) → resolve_url。
  • 正则避坑：Dart RegExp 不支持 PCRE 内联标志（如 (?i)）；errors.rules 已默认大小写不敏感，切勿手写 (?i)。

Step 5 · 导入 Echo 与安全隔离

导入客户端，放心更新、分享不泄密

Echo 客户端物理隔离了规则定义、用户网络覆盖与账号凭据，并在「书源管理」页面提供四种开箱即用的添加途径。

1. 规则注册表层

位于 registry.json。存放内置公版源、远程订阅拉取的 Bundle 与本地导入定义；订阅按 config_ttl_hours 自动刷新时仅更新此层。

2. 用户配置覆盖层

位于 overlays.json。独立存储开关状态、优选镜像、自定义域名、反代前缀与当前搜索书源，订阅更新绝不覆盖个人配置。

3. 凭据保险箱层

使用系统 FlutterSecureStorage 加密保管账号 Cookie / Token 与额度摘要；单源导出分享时走白名单序列化，从结构上物理隔绝私密凭据。

方式 1

URL 订阅

打开「我的 → 书源管理 → + → URL 订阅」，输入托管 Bundle JSON 的 https:// 地址，支持定时增量刷新。

方式 2

导入 JSON

切换至「导入 JSON」标签，可从设备选择 .json 文件或直接粘贴通过校验器验证的文本立即生效。

方式 3

OPDS 书库

切换至「OPDS 书库」表单，填入 Calibre / Komga 等目录地址与可选用户名密码，免写 JSON 一键接入。

1. 正则表达式在浏览器好使，导入 App 却报错 FormatException？
  • Dart 的 RegExp 不支持 PCRE 内联标志（例如 (?i)、(?s)）。请移除此类内联标志；errors.rules 匹配错误消息时已自动启用大小写不敏感。
2. JSON 对象的键名自带 / 或 .（如 application/epub+zip）取不到值？
  • path 按 . 切分路径，遇到键名本身包含小数点（如 text/plain; charset=utf-8 或版本号）时会出错。请改用精确键名数组 "path_segments": ["formats", "application/epub+zip"]。
3. 搜书结果封面裂图或返回 403？
  • 部分站点图片 CDN 会校验防盗链 Referer 或浏览器 User-Agent。请在顶层配置 image_headers（App 内所有封面渲染组件均已透传该请求头），并确保规则开启 "resolve_url": true。
4. 下载跳到第三方对象存储/CDN，或匿名调用状态接口也返回 200？
  • 如果最终下载链接在第三方 CDN 域名，务必设置 "same_origin_credentials": false（或在需同源鉴权时保持 true，客户端跨域重定向时会自动剥离 Cookie 与敏感头）。
  • 如果站方 /auth/status 匿名也返回 200，请在 auth.verify.steps 中把会返回 401 的受保护接口（例如配额查询）放在第一位，防止过期会话误判。
