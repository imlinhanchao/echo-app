三分钟部署书源服务
解锁 Echo 在线搜书

ebook-api 是专为 Echo 打造的单一 Go 可执行服务，无需安装数据库、零外部依赖。Echo 默认可直接跳过配置、纯本地导入 EPUB / TXT 开读；随时按本页步骤自建书源服务后，即可直接在客户端搜索与流式下载电子书。

立即开始部署 二进制 / Docker / Windows / systemd 生成 .env 配置
  • 单文件即运行
  • 无数据库 · 内存即用
  • Docker / NAS / PC 全支持
  • 可选配 · 可随时跳过
按你的环境选部署路线 :8091
局域网 家里电脑 / NAS / 局域网 监听 0.0.0.0:8091，手机连同一 Wi-Fi 的局域网 IP 即可直连 → 公网 HTTPS 云服务器 / 随时随地搜书 配 EBOOK_API_KEY + 固定 EBOOK_SECRET + Caddy / Nginx 反代 → 零部署 只读本地 EPUB / TXT 无需搭建任何服务，在 Echo 内点击「跳过书源配置」直接使用 →
Step 1 · 安装运行

选择部署方式

下载预编译包解压即可运行；若部署在 NAS 或云服务器，推荐使用 Docker Compose 或 systemd 长期守护。

适合 Linux 服务器或 macOS 本机运行：上方下载对应架构包（macOS M 系列芯片选 darwin_arm64.tar.gz），解压后改监听为 0.0.0.0:8091 即可让手机直连。

1. 解压、配置 .env 并启动（macOS 同理，压缩包名改为 darwin_arm64） 
tar -xzf ebook-api_v0.1.0_linux_amd64.tar.gz
cd ebook-api_v0.1.0_linux_amd64
cp .env.example .env

# 允许局域网内的 Echo 客户端访问；若在本机跑反代请保留 127.0.0.1:8091
sed -i.bak 's/^EBOOK_ADDR=.*/EBOOK_ADDR=0.0.0.0:8091/' .env && rm -f .env.bak

./ebook-api
2. 启动自检（确认服务在线与内置控制台可达） 
curl -s http://127.0.0.1:8091/health
# 返回 {"ok":true,...} 后，浏览器访问 http://<你的设备IP>:8091/ 可打开 Web 调试台

适合 Docker 宿主机与群晖 / 威联通 / 飞牛等 NAS：默认已绑定 0.0.0.0:8091。务必挂载 ./data:/app/data，保证重装或升级容器后已生成的 secret.key 不丢失。

1. 推荐挂载持久化卷的 docker-compose.yml（或 override） 
services:
  ebook-api:
    build: .
    container_name: ebook-api
    restart: unless-stopped
    ports:
      - "8091:8091"
    env_file:
      - path: .env
        required: false
    environment:
      EBOOK_ADDR: 0.0.0.0:8091
    volumes:
      - ./data:/app/data
2. 构建启动、查看日志与日常升级 
git clone https://github.com/imlinhanchao/ebook-api.git
cd ebook-api
cp .env.example .env

# 按需在下方「生成 .env 配置」填入参数后启动
docker compose up -d --build
docker compose logs -f ebook-api

# 日常升级命令
git pull && docker compose up -d --build

NAS 图形面板提示：在 Container Manager / Docker 管理界面导入仓库后，映射端口 8091:8091 与路径 /app/data，确认 NAS 防火墙放行 8091 即可。

适合在家里 Windows 电脑临时或开机挂机充当书源节点：上方下载 windows_amd64.zip 并解压到任意目录（如 D:\ebook-api）。

PowerShell 配置局域网监听并启动 
cd D:\ebook-api
Copy-Item .env.example .env
(Get-Content .env) -replace '^EBOOK_ADDR=.*', 'EBOOK_ADDR=0.0.0.0:8091' | Set-Content .env

# 首次运行如弹出 Windows Defender 防火墙提示，请勾选「专用网络」并允许访问
.\ebook-api.exe
查看电脑局域网 IP（供手机 Echo 填写） 
ipconfig | findstr IPv4
# 取局域网 IPv4（例如 192.168.1.10），在 Echo 中填写 http://192.168.1.10:8091

适合 Linux 服务器或迷你主机后台常驻与崩溃自启：按模板把二进制放至 /opt/ebook-api/bin/ebook-api 并注册用户级 systemd 服务。

1. 部署目录与启用后台服务 
mkdir -p /opt/ebook-api/bin /opt/ebook-api/data /opt/ebook-api/.tmp ~/.config/systemd/user
# 将解压后的 ebook-api 二进制放入 /opt/ebook-api/bin/ebook-api，.env 与 static/ 放入 /opt/ebook-api/
sed "s|__APP_DIR__|/opt/ebook-api|g" deploy/ebook-api.service > ~/.config/systemd/user/ebook-api.service

systemctl --user daemon-reload
systemctl --user enable --now ebook-api
sudo loginctl enable-linger "$USER"
2. 查看运行日志与升级重启 
systemctl --user status ebook-api
tail -f /opt/ebook-api/.tmp/ebook-api.log

# 替换新版本二进制后重启服务
systemctl --user restart ebook-api

需要 Go 1.24+ 从源码编译、查看完整环境变量说明、HTTP API 参考或扩展新书源，请参阅 Ebook API GitHub 仓库。

Step 2 · 生成配置

交互式生成 .env 配置文件

根据部署场景勾选选项、一键生成随机密钥，直接复制到服务根目录的 .env 文件即可启动。

访问方式（决定 EBOOK_ADDR）
生成的 .env 内容（纯浏览器本地生成，不上传） 
EBOOK_ADDR=0.0.0.0:8091
EBOOK_DATA_DIR=data
# 留空则首次启动自动生成并持久化到 data/secret.key
# EBOOK_SECRET=
EBOOK_ALLOW_PLAIN_CRED_HEADERS=false
ZLIB_DOMAINS=https://z-lib.gd,https://z-lib.gl,https://z-library.ec,https://zlib.bz
  • EBOOK_ADDR：家里电脑/NAS 让手机直连选 0.0.0.0；有 Caddy/Nginx 挡在前面选 127.0.0.1 避免裸端口暴露公网。
  • EBOOK_API_KEY：公网部署强烈建议生成并填写，Echo 连接服务时同步输入此 Key 即可鉴权。
  • EBOOK_SECRET：固定 64 位 Hex 主密钥后，容器重建、迁移或更换机器时，Echo 已保存的 ebk1.* 书源令牌依然有效。
Step 3 · 公网 HTTPS（可选）

Caddy / Nginx 反向代理配置

需要在外网随时搜书时，建议将 ebook-api 仅监听 127.0.0.1:8091 并配置 HTTPS 反向代理。下载接口为流式大文件透传，请关闭代理缓冲。

Caddyfile（自动签发 HTTPS 证书，推荐） 
ebook.example.com {
    reverse_proxy 127.0.0.1:8091 {
        # 关闭输出缓冲，立即向客户端透传图书下载流
        flush_interval -1
    }
}
Nginx Server Block（关闭缓冲并延长下载超时） 
server {
    listen 443 ssl http2;
    server_name ebook.example.com;

    location / {
        proxy_pass http://127.0.0.1:8091;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_buffering off;
        proxy_read_timeout 300s;
    }
}

CDN 回源省配额提示：下载路径 /v1/providers/*/books/*/download 跨账号固定且自带长期 Cache-Control 与 ETag；在 .env 勾选 EBOOK_PUBLIC_DOWNLOAD=true 与服务端默认凭据并让 CDN 按纯 URL 缓存，命中后不再消耗上游每日下载额度。

Step 4 · 客户端绑定

三步接入 Echo 客户端

服务端上线后，在 Echo 手机或桌面端完成绑定即可搜索并下载；暂不部署也可在引导页随时跳过，仅用本地导入。

01

确认服务可访问

在手机或电脑浏览器打开 http://<你的IP或域名>:8091/，能看到内置书源测试台（或访问 /health 返回 ok: true）即表示网络端口与进程已通。

02

在 Echo 填入服务地址

在首次引导第 1 步，或「我的 → ebook-api 书源服务」/「发现 → 配置服务」输入服务 URL 与可选 API Key，点击「测试连接」显示可用书源后保存。

03

登录书源开始搜书

前往「我的 → 书源账号」选择可用镜像并完成账密或 Cookie 登录即可搜书；若后续只想纯本地读导入书，可在设置页点击「跳过 / 清空书源配置」。

常见卡点

部署常见排错

90% 的部署问题集中在监听地址、防火墙放行与容器密钥持久化，按下方条目逐项核对即可快速解决。

1. 手机连不上电脑 / NAS 的 8091 端口？
  • 检查 .env 中是否为 EBOOK_ADDR=0.0.0.0:8091（默认的 127.0.0.1:8091 仅允许本机访问）。
  • 确认宿主机防火墙（Linux ufw / firewalld、Windows 专用网络防火墙、云服务器安全组）已放行 8091 端口，且手机与主机处于同一局域网网段。
2. 容器重建或迁移后，Echo 提示书源会话失效？
  • 每次重新生成容器且未挂载 /app/data 时，服务端会生成新的随机密钥，导致客户端本地保存的 ebk1.* 加密令牌无法解封。
  • 请在 docker-compose.yml 挂载 ./data:/app/data，或在 .env 显式固定 32 字节的 EBOOK_SECRET 后在 Echo「书源账号」重新保存一次即可一劳永逸。
3. 经过反代后下载大体积电子书超时或卡顿？
  • 确保反代未启用默认响应缓冲并放宽上游读取超时：Nginx 务必配置 proxy_buffering off; 与 proxy_read_timeout 300s;，Caddy 配置 flush_interval -1。
4. 搜索超时或提示镜像被拦截（503）？
  • 这通常说明当前选中的 Z-Library 镜像与部署主机之间连通受阻或触发站点风控；请在 Echo「我的 → 书源账号」测试并切换其他可用镜像，或在服务端 .env 调整 ZLIB_DOMAINS 顺位。
