自建 Ebook API
专属书源服务

ebook-api 是为 Echo（回声）打造的独立多书源搜索与流式下载 HTTP 服务，采用纯 Go 标准库零依赖构建。Echo 默认可直接跳过配置、纯本地导入 EPUB / TXT 开读；当你需要在客户端内联搜书下载时，只需数分钟部署并填入服务地址。

每个发行压缩包均已内置 static/ 测试台、.env.example 与配置模板，解压即可单文件运行。若需局域网内手机或平板连接，请将 EBOOK_ADDR 设为 0.0.0.0:8091。

Linux / macOS 解压与启动示例 
tar -xzf ebook-api_v0.1.0_linux_amd64.tar.gz
cd ebook-api_v0.1.0_linux_amd64
cp .env.example .env

# 需局域网/移动端访问时改监听 0.0.0.0（按需设置 EBOOK_API_KEY）
sed -i 's/^EBOOK_ADDR=.*/EBOOK_ADDR=0.0.0.0:8091/' .env

./ebook-api
启动后连通性自检 
curl -s http://127.0.0.1:8091/health
# 浏览器打开 http://<你的设备或服务器IP>:8091/ 可进入内置 Web 调试台

项目根目录自带多阶段构建 Dockerfile 与 docker-compose.yml（基于 distroless/static-debian12:nonroot，默认已监听 0.0.0.0:8091 并映射 8091:8091）。为避免容器重建后导致客户端缓存的 ebk1.* 令牌失效，建议固定 EBOOK_SECRET 或挂载 /app/data 卷。

Docker Compose 一键启动 
git clone https://github.com/imlinhanchao/ebook-api.git
cd ebook-api
cp .env.example .env
docker compose up -d --build
docker compose logs -f ebook-api
推荐：追加 docker-compose.override.yml 持久化 /app/data 
services:
  ebook-api:
    volumes:
      - ./data:/app/data

Linux 发行包与源码仓库内置 deploy/ebook-api.service 模板，可将 __APP_DIR__ 替换为你的安装目录并托管为用户级常驻服务（日志自动写入 .tmp/ebook-api.log，默认读取可执行文件位于 __APP_DIR__/bin/ebook-api）。

systemd --user 后台托管 
mkdir -p ~/.config/systemd/user /opt/ebook-api/.tmp
sed "s|__APP_DIR__|/opt/ebook-api|g" deploy/ebook-api.service > ~/.config/systemd/user/ebook-api.service
systemctl --user daemon-reload
systemctl --user enable --now ebook-api
systemctl --user status ebook-api
允许退出 SSH 会话后继续常驻运行 
sudo loginctl enable-linger "$USER"
tail -f /opt/ebook-api/.tmp/ebook-api.log

本地需安装 Go 1.24+。仓库无任何第三方 Go 模块依赖，可直接通过 Makefile 编译静态可执行文件或运行全套测试。

Go 源码编译与测试

cd ebook-api

# 校验与并发竞争测试
make test

# 编译至 bin/ebook-api 并运行

1. 局域网 / 手机端连接须改监听地址

.env.example 默认绑定 127.0.0.1:8091，仅限本机回环访问。手机等设备需连接时，请修改为 EBOOK_ADDR=0.0.0.0:8091 并放行服务器/系统防火墙的 8091 端口，或由 Nginx / Caddy 反向代理。

2. 公网暴露务必启用 API Key

面向公网部署时请设置强随机 EBOOK_API_KEY，并保持 EBOOK_ALLOW_PLAIN_CRED_HEADERS=false，确保客户端仅携带加密令牌请求服务。

3. 固定密钥以免加密令牌失效

未设置 EBOOK_SECRET 时服务会自动生成并持久化到 <EBOOK_DATA_DIR>/secret.key。多实例或容器重建场景建议显式填写 32 字节 EBOOK_SECRET（base64 或 hex）或挂载数据卷。

客户端联动

在 Echo 客户端接入使用

服务运行后，按以下四步即可完成连通性验证、客户端绑定与在线搜书；若暂无自建需求也可随时停用，保留纯本地导入。

01

验证服务与内置调试台

先确认服务可访问：浏览器打开 http://<你的地址>:8091/ 可直接测试书源登录与查书，或请求 GET /health 检查已启用书源列表中是否包含 zlib。

02

在 Echo 填写书源地址

首次启动引导第 1 步，或前往「我的 → ebook-api 书源服务」/「发现」页右上角「配置服务」，输入例如 http://192.168.1.10:8091 与可选 API Key，点击「测试连接」通过后保存。

03

配置书源账号与配额

进入「我的 → 书源账号」，选择可用的 Z-Library 镜像域名，支持「邮箱密码」或粘贴浏览器 Cookie（remix_userid / remix_userkey）自动封装为加密 ebk1.* 令牌并验证配额。

04

在线搜书或随时切回本地

配置完成后「发现」页立即解锁搜索与格式/语言/年份筛选，支持下载入库或直接转有声书。若日后只想读本地书，可在设置页点击「跳过 / 清空书源配置（仅使用本地导入）」。

参数清单

环境变量与反向代理配置

程序启动时自动加载同目录的 .env 文件，已设置的系统环境变量优先级更高。

环境变量 默认值 说明与建议
EBOOK_ADDR 127.0.0.1:8091 HTTP 监听地址；局域网/容器访问请设为 0.0.0.0:8091
EBOOK_API_KEY 空（不鉴权） 服务级鉴权密钥；除 /health 外均校验 Bearer / X-API-Key
EBOOK_SECRET 自动生成 32 字节 AES-256-GCM 密钥（base64 或 hex），用于加解密 credential_token
EBOOK_DATA_DIR data 数据目录；未指定 EBOOK_SECRET 时自动在此持久化 secret.key
EBOOK_STATIC_DIR static 内置前端调试台目录（磁盘缺失自动回退内嵌资源；设为 off 可关闭 UI）
EBOOK_DEFAULT_PROVIDER zlib 调用 /v1/search 未指定 provider 时使用的默认书源 ID
EBOOK_ENABLED_PROVIDERS 空（全部启用） 启用的书源白名单，逗号分隔（例如 zlib）
ZLIB_DOMAINS https://z-lib.gd,... Z-Library 镜像列表，逗号分隔并按优先级自动健康探测与故障切换
ZLIB_DOMAIN / ZLIB_REMIX_* 空 服务端默认 Z-Library 凭据（ZLIB_REMIX_USERID / ZLIB_REMIX_USERKEY），请求未带令牌时兜底
EBOOK_CRED_<PROVIDER>_<KEY> 空 任意自定义书源的通用默认凭据注入格式
EBOOK_PUBLIC_DOWNLOAD false 设为 true 时 GET 下载接口放行无 EBOOK_API_KEY 校验，方便接入 CDN 回源
EBOOK_DOWNLOAD_CACHE_CONTROL public, max-age=2592000, immutable 图书下载流响应的 Cache-Control 头，配合 ETag 减少重复下载与配额损耗
EBOOK_MAX_DOWNLOAD_MB 500 单本图书最大下载体积上限（MB），设为 0 表示不限制
EBOOK_ALLOW_PLAIN_CRED_HEADERS false 是否允许明文凭据请求头；生产环境强烈建议保持 false
EBOOK_CORS_ORIGINS 空 允许跨域调用的 Origin 列表，逗号分隔（* 表示允许所有）
推荐公网部署 .env 示例 
EBOOK_ADDR=127.0.0.1:8091
EBOOK_DATA_DIR=/opt/ebook-api/data
EBOOK_API_KEY=请替换为高强度随机密钥

EBOOK_SECRET=请替换为32字节Base64或Hex密钥

Nginx HTTPS 反向代理与 CDN 缓存提示 
location / {
    proxy_pass http://127.0.0.1:8091;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    # 大文件流式透传，关闭代理缓冲降低内存与首字节延迟
    proxy_buffering off;
    proxy_read_timeout 300s;
}

开发与排错

双层认证、API 速查与常见问题

便于二次开发自定义书源、使用 curl 调试接口，以及快速定位常见连接或上游异常。

双层分离认证设计

服务级鉴权由 Authorization: Bearer <EBOOK_API_KEY> 或 X-API-Key 控制；书源级凭据则由服务端用 AES-256-GCM 封装为绑定书源 ID 的 ebk1.* 不透明令牌，通过 X-Provider-Token 回传。合并优先级：POST credential_token > POST credentials > X-Provider-Token > X-Provider-Domain > .env 服务端默认凭据。

插件化扩展新书源

在 internal/providers/<source>/ 实现 Provider 核心接口（ID / DisplayName / Capabilities / Search / GetBook / OpenDownload），按需实现 InfoProvider、Verifier、PasswordAuthenticator、DomainProber 等可选接口并在 cmd/ebook-api/main.go 的 registerProviders 注册，即可自动接入聚合搜索与加密令牌。

方法 路径 用途
GET / · /health 内置前端测试台 · 健康检查（返回版本号与已启用书源列表）
GET /v1/providers · /v1/providers/{id} 获取已注册书源及其支持的能力与凭据字段元数据
POST /v1/providers/{id}/login · /seal 账密登录或封装已有 Cookie，生成加密 credential_token
POST /v1/providers/{id}/verify · /probe 校验令牌有效性及每日下载配额 · 探测上游镜像连通性
GET POST /v1/search 搜索图书（支持 ext / lang / year_from / order 及 provider=all 聚合）
GET POST /v1/providers/{id}/books/{ref} 获取单本图书简介、页数、体积、格式与可下载引用
GET POST /v1/providers/{id}/books/{ref}/download 流式透传图书文件，响应附带确定性 ETag 与 Cache-Control
curl 端到端调试示例（封装令牌 + 搜书 + 下载） 
# 1. 登录换取加密令牌（或调用 /seal 传入 Cookie）
TOKEN=$(curl -s -X POST http://127.0.0.1:8091/v1/providers/zlib/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"your-password"}' | jq -r .credential_token)

# 2. 搜索 EPUB 图书
curl -s "http://127.0.0.1:8091/v1/search?q=%E4%B8%89%E4%BD%93&provider=zlib&ext=epub&limit=10" \
  -H "X-Provider-Token: $TOKEN"

# 3. 按书源返回 ref 流式下载
curl -L -J -O "http://127.0.0.1:8091/v1/providers/zlib/books/123456:abcdef/download" \
  -H "X-Provider-Token: $TOKEN"
手机客户端「测试连接」超时或无法连上自建服务？
  • 检查 EBOOK_ADDR 是否仍为默认的 127.0.0.1:8091；手机与电脑处于同一局域网时请改为 0.0.0.0:8091 并使用电脑局域网 IP（如 http://192.168.1.10:8091）。
  • 确认宿主机防火墙（如 ufw / 防火墙规则）或云服务器安全组已放行对应端口；公网环境建议使用域名搭配 HTTPS 反向代理。
返回 401 UNAUTHORIZED 或 SESSION_EXPIRED 怎么办？
  • UNAUTHORIZED：服务端启用了 EBOOK_API_KEY，请在 Echo 客户端的「ebook-api 书源服务」补填匹配的 API Key。
  • SESSION_EXPIRED：常见于上游账号 Cookie 过期，或服务重启/重建容器后变更了 EBOOK_SECRET。请固定 EBOOK_SECRET 后在「书源账号」重新登录或导入 Cookie。
返回 403 QUOTA_EXCEEDED 或 409 PROVIDER_NOT_CONFIGURED？
  • QUOTA_EXCEEDED：当前账号今日在上游站点的免费下载额度已用完，可在「书源账号」更换账号，或借助 CDN 缓存热门书籍下载流。
  • PROVIDER_NOT_CONFIGURED：请求未附带有效 X-Provider-Token 且服务端未配置 ZLIB_REMIX_USERID / ZLIB_REMIX_USERKEY 回退凭据，请前往 Echo「我的 → 书源账号」完成登录验证。
遇到 503 PROVIDER_BLOCKED 或镜像不可达？
  • 表示当前使用的镜像域名触发了 Cloudflare 或上游站点的风控拦截，或部署主机与该镜像之间网络受限。
  • 建议在 Echo「书源账号」切换其他可用镜像域名，或编辑服务端的 ZLIB_DOMAINS 调整镜像优先级与备用列表。
